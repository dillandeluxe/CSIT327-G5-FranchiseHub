Troubleshooting Tips

01

Clear Browser Cache

If data doesn't update or pages load slowly, clear your browser cache and refresh the page.

02

Re-login

If buttons stop working or features become unresponsive, try logging out and logging back in.

03

Check Internet Connection

Ensure you have a stable internet connection. Try reloading the page if content doesn't load.

04

Use Supported Browsers

We recommend using the latest versions of Chrome, Edge, Firefox, or Safari for the best experience.

05

Disable Extensions

Some browser extensions may interfere with functionality. Try disabling them temporarily.
